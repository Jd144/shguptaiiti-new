# BPBME Lab Website

Biophysics & Biomedical Engineering Research Group — IIT Indore.

This repository is the clean rebuild of the lab website. The original `Jd144/shguptaiiti` repository is intentionally left untouched.

## Structure

- `index.html` — public application shell
- `admin/index.html` — admin portal entry
- `css/` — modular styles
- `js/` — modular application/CMS logic
- `assets/images/` — image assets
- `vercel.json` — Vercel routing

## Stack

HTML, CSS, JavaScript, Tailwind CSS, Alpine.js, Firebase Auth and Firestore, Lucide Icons.
